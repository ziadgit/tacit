# TypeRoles

Five type roles, each with one job.

- Wordmark: Geist Pixel with fine dots, for the word `tacit` only.
- Titles: Instrument Serif, lower case. Use the italic for a line that speaks: the tagline, a section phrase such as "what maya never wrote down", the word for a group.
- Body: Instrument Sans. On a projector set steps and explanations at 20px or larger.
- People: Caveat, only for a person's name and their own words. Never for headings, buttons or interface text.
- Paths and time: IBM Plex Mono, for a real file path or a time code.

To confirm: small capital labels in the mono font ("SKILL · 1 MIN", "SEE IT WORK") are on the liked skill card, but the same style was turned down on the profile. Until that is settled, write section headings as plain phrases in italic serif.
