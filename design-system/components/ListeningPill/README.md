# ListeningPill

A blue pill that says the band is listening; it is the only blue thing in tacit.

- Markup: `<div class="tc-pill"><span class="tc-bud">` with nine empty `<i>` inside, then the word `Listening`.
- Place it in the top right corner of a screen, 20px from the edges.
- The white outline and the soft halo are part of it; they keep it readable on lavender.
- Show it only while the microphone is really on. A screen with no microphone has no blue at all.
