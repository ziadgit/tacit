# Wordmark

The word `tacit` in lower case, set in Geist Pixel with fine dots, filled with the cream-pink-blue gradient on the ground or with `ink` on paper.

- Use class `tc-word` and set only the font size. The dot look is `font-variation-settings: "ELSH" 50`; do not change it and do not add letter spacing.
- Write the word as `tac<span class="bi">i</span>t`. The dot of the i is then drawn as a small cluster of dots: white around, blue-indigo (`dot`) in the centre. It is not the listening blue.
- On paper add class `ink`.
- The tagline sits under it in italic serif (`tc-line`), lower case: *agents have skills. people have taste. tacit is how it gets around.*
- Sizes: about 110px as the main word of a screen, about 48px in a corner. Do not go under 29px.
- Never capitalise it, never set it in the serif or the handwriting. The dot font is for this word only.
